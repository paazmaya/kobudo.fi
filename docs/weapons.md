# The Weapons

1. **Bō**: 6ft staff.
2. **Sai**: Metal trident.
3. **Tonfa**: Side-handled baton.

![Weapon Set](https://placehold.co/800x400/800000/white?text=Core+Weapon+Display)

The "Ryukyu Kobudo Daikan" describes the core 8 weapons: Bō, Sai, Tonfa, Nunchaku, Kama, Tekko, Tinbe-Rochin, and Surujin.
