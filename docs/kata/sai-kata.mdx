Taira-linjassa on säilynyt kahdeksan sai-kataa. Bushukan-tutkimusryhmän (武集館) analyysi tunnistaa selkeitä rakenteellisia suhteita näiden kahdeksan muodon välillä ja jakaa ne kolmeen perheryhmään yhteisten liikesarjojen, embusenin (liikeradan) ja taktisen painotuksen perusteella. Katso [Taira-linjan opetusohjelmasta](/tyylit/taira-linja#curriculum), miten nämä sopivat laajempaan kahdeksan aseen järjestelmään.

## Kolmen klusterin analyysi {/* #the-three-cluster-analysis */}

Bushukan-analyysi lähtee havainnosta, että Taira liitti seitsemän kahdeksasta sai-katastaan historialliseen perinteeseen, kun taas **Jigen no Sai** tunnistetaan nimenomaisesti hänen omaksi luomuksekseen. Näin vertailtavaksi jää seitsemän "vanhaa muotoa".

### Klusteri 1: Hamahiga-perhe {/* #cluster-1-the-hamahiga-family */}

**浜比嘉の釵 (Hamahiga no Sai)** esitetään rakenteellisena "lähdemuotona". Sen liikesarjat toistuvat kahdessa läheisesti liittyvässä katassa:

| Kata                  | Japani           | Suhde                                                              |
| --------------------- | ---------------- | ------------------------------------------------------------------ |
| Hamahiga no Sai       | 浜比尌の釵       | Lähdemuoto: rakenteelliset elementit toistuvat molemmissa alla     |
| Hamagoten yaka no Sai | 浜御殿屋可阿の釵 | Sisältää monia samoja liikejaksoja kuin Hamahiga; läheisesti sukua |
| Hantagwa no Sai       | 端多小の釵       | Rakenteellisesti lähellä; samankaltainen embusen ja tekniikat      |

Nämä kolme muodostavat yhden alaryhmän: Hamahigan rakennemallin laajennuksia tai uudelleenjärjestelyjä.

### Klusteri 2: Tsuken–Chatan–Tawada-perhe {/* #cluster-2-the-tsukenchatantawada-family */}

Toisen tiiviin ryhmän katoilla on monia yhteisiä liikesarjoja ja taktisia ajatuksia, jotka erottavat ne Hamahiga-ryhmästä:

| Kata                    | Japani         | Suhde                                                                  |
| ----------------------- | -------------- | ---------------------------------------------------------------------- |
| Tsuken Shitahaku no Sai | 津堅志多伯の釵 | Tämän alaryhmän ydin                                                   |
| Chatan Yara no Sai      | 北谷屋良の釵   | Sisältää keskeisiä samoja liikejaksoja kuin Tsuken Shitahaku ja Tawada |
| Tawada no Sai           | 多和田の釵     | Sama "perhe" eri painotuksin ja yhdistävin askelin                     |

Bushukan-analyysi ehdottaa, että nämä kolme jakavat yhteisen taustakuvion, joka myöhemmin eriytyi kolmeksi erilliseksi kataksi.

### Klusteri 3: Kochijo–Jigen-pari {/* #cluster-3-the-kochijojigen-pair */}

| Kata           | Japani   | Suhde                                                          |
| -------------- | -------- | -------------------------------------------------------------- |
| Kochijo no Sai | 湖城の釵 | Luettu Tairan kahdeksan sai-katan joukkoon                     |
| Jigen no Sai   | 慈元の釵 | Tairan oma luova työ; nimenomaisesti "lähes sama kuin Kochijo" |

**Jigen no Sai** suoritetaan **manji-sailla** (卍釵), sain muunnelmalla, jossa piikit kaareutuvat vastakkaisiin suuntiin. Taira mukautti Kochijon rakenteen hyödyntämään tämän aseen erityistä muotoa ja lisäsi tiheämmin toistuvia _hon-te_-pistoja (pistoja tavanomaisella otteella). Tuloksena on toiminnallisesti Kochijon luova muunnelma itsenäisen katan sijaan.

## Sisäinen karttayhteenveto

```
Hamahiga-perhe:
  浜比嘉の釵  →  浜御殿屋可阿の釵
             →  端多小の釵

Tsuken–Chatan–Tawada-perhe:
  津堅志多伯の釵  ↔  北谷屋良の釵  ↔  多和田の釵

Kochijo–Jigen-pari:
  湖城の釵  →  慈元の釵 (Tairan luova sovellus, manji-sai)
```

## Tyylienvälinen esiintyminen

Kaikki viisi ryhmien juurinimeä (Hamahiga, Chatan Yara, Tsuken, Tawada ja Kochijo) esiintyvät myös usean organisaation kobudo-kataluetteloissa, mikä vahvistaa, että muut koulut ovat sisällyttäneet ohjelmiinsa näiden perheiden versioita. Koreografiat eroavat, mutta perheiden juuret ovat yhteisiä.
