Taira Shinkenin opetusohjelma järjestää Ryukyu kobudon kahdeksan perusaseen ympärille. Jokaisella aseella on oma historiansa, mekaniikkansa ja kata-kokoelmansa. Osa kehitettiin maatalous- tai merityökaluista, toiset taas olivat Pechin-soturiluokan erikoisaseita.

## Kahdeksan asetta

| Ase                            | Japani             | Alkuperä/luonne                                         | Kata (Taira-linja) |
| ------------------------------ | ------------------ | ------------------------------------------------------- | ------------------ |
| [Bō](./bo)                     | 棒                 | 1,8 m sauva, yleisin ase                                | 18+                |
| [Sai](./sai)                   | 釵                 | Metallinen kolmikärki pistoihin, sitomiseen ja iskuihin | 8                  |
| [Tonfa](./tonfa)               | トンファー         | Kivimyllyn kahva, lähietäisyys                          | 2                  |
| [Nunchaku](./nunchaku)         | ヌンチャク         | Varstatyyppinen, alkuperänä puimatyökalu                | 2                  |
| [Kama](./kama)                 | 鎌                 | Sirppi, maataloustyökalu                                | 2                  |
| [Tekko](./tekko)               | 鉄甲               | Nyrkkisuojat, johdettu hevosenkengästä                  | 2                  |
| [Tinbē-Rochin](./tinbe-rochin) | ティンベー・ロチン | Kilpi ja lyhyt keihäs                                   | 1                  |
| [Surujin](./surujin)           | スルジン           | Painotettu köysi tai ketju etäisyyden hallintaan        | 2                  |

## Kahdeksan aseen lisäksi

Vaikka Taira / Hozon Shinkōkai -opetusohjelma keskittyy kahdeksaan aseeseen, laajempi Ryukyu kobudon perinne sisältää lisävälineitä. [Matayoshi-opetus](/tyylit/matayoshi) lisää esimerkiksi:

| Ase              | Japani            | Kuvaus                                                       |
| ---------------- | ----------------- | ------------------------------------------------------------ |
| [Eku](./eku)     | 櫂 / エーク       | Veneen airo, erityisesti Tsuken-saaren perinteeseen liittyvä |
| [Kuwa](./kuwa)   | 鍬                | Kuokka, kaivuutyökalu, jolla myös heitetään maata            |
| [Nunti](./nunti) | 貫手棒 / ヌンティ | Kolmikeihäs, joka yhdistää sai- ja keihästekniikat           |
| **Sansetsukon**  | 三節棍            | Kolmiosainen sauva                                           |
| **Jō**           | 杖                | Lyhyempi sauva (~1,2 m)                                      |

Nämä lisäaseet heijastavat Matayoshi-opetuksen painotusta jokapäiväisistä esineistä peräisin oleviin aseisiin sekä kiinalaisvaikutteisiin taisteluvälineisiin. Eku ja kuwa ovat esimerkkejä kalastus- ja maatalousvälineistä, joista tuli aseita, kun taas nunti yhdistää keihäs- ja sai-tekniikat omaleimaisen manji-sai-kärkensä avulla.

## Miksi nämä kahdeksan?

Tasan kahdeksan aseen ryhmitys on Taira Shinkenin järjestelmällisen opetuksen valinta, ei muinainen kanoninen luettelo. Valinnassa painottuvat aseet, joilla on useita säilyneitä kata-perheitä, mikä tarjoaa monipuolisen opetusohjelman jokaiselle tasolle. Se heijastaa myös sitä, mille aseille Taira löysi elävää opetusta useilta opettajilta — käytännöllinen valinta aikana, jolloin monet linjat olivat vaarassa kadota.
