# Tinbē-Rochin (ティンベー・ロチン)

**Tinbē-Rochin** (ティンベー・ロチン) on aseyhdistelmä: **tinbē** on pieni pyöreä kilpi, joka on perinteisesti tehty rottingista, nahasta tai **kilpikonnan kuoresta**, kun taas **rochin** on lyhyt keihäs tai terä. Yhdistelmä on yksi Ryukyu kobudon visuaalisesti erottuvimmista ja ainoa asepari, joka yhdistää puolustusvälineen ja hyökkäysaseen kokonaisuudeksi.

JRKF:n "Mitä on Ryukyu Kobudo" -sivun mukaan **tinbē** (kilpi) ja **rōchin** (lyhyt keihäs) muodostavat aseparin. Kilvet tehtiin perinteisesti **rottingista, nahasta tai kilpikonnan kuoresta**, kun taas rōchin saattoi olla lyhyt keihäs tai **macheten kaltainen terä (seiryuto / 青龍刀)**. Molempia voitiin käyttää harhautuksiin, sokaisemiseen, leikkaamiseen ja pistoihin. Nykyaikainen tinbē voidaan tehdä **kevytmetalliseoksista tai puusta**, mutta taktinen ajatus säilyy: **kilpeä käytetään suojaukseen, näkyvyyden häirintään ja reunaiskuihin, kun taas rochinilla pistetään ja leikataan**. Tämä muistuttaa eteläkiinalaisia kilpi- ja keihäsjärjestelmiä.

揆奮館 jäljittää tinbē-tekniikat **eteläiseen Shaoliniin (南派小林拳の流れをくむ)** ja esittää, että ne olivat käytössä Ryukyun **kolmen kuningaskunnan eli Sanzanin (三山) kaudella**, mikä tekisi tinbēstä yhden **vanhimmista kerrostumista** ryukyulaisessa aseharjoittelussa.

## Fyysiset ominaisuudet

| Komponentti     | Ominaisuus             | Yksityiskohta                                              |
| --------------- | ---------------------- | ---------------------------------------------------------- |
| Tinbē (kilpi)   | Koko                   | ~45 cm pitkä × 38 cm leveä                                 |
|                 | Perinteinen materiaali | Merikilpikonnan kuori tai kudottu rottinki/köynnös         |
|                 | Moderni korvike        | Kovetettu nahka tai puu                                    |
| Rochin (keihäs) | Pituus                 | Vastaava kuin kyynärvarren pituus                          |

|                 | Materiaali             | Metalli, luu tai kovapuu                                   |

## Taktinen logiikka

Yhdistelmää pidetään kansainvälisesti epätavallisena, koska siinä käytetään erillistä puolustusvälinettä hyökkäysaseen parina. Tinbē mahdollistaa taistelun lähietäisyydellä, jossa pitkä ase olisi kömpelö: kilpi torjuu ja rochin pistää tai leikkaa samalla liikkeellä. Liike on tyypillisesti matalaa ja väistävää; kilvellä luodaan kulmia, joista rochin voi hyödyntää aukkoja.

## Kata

Tairan opetussuunnitelma sisältää yhden ensisijaisen tinbē-rochin-katan:

- **Hamahiga no Tinbē** (浜比尌のティンベー): Peruskata, joka kattaa jalkatyön, kilven kulmat ja työntöyhdistelmät. Liike on tyypillisesti ympyrämäistä liiallisen kilpikosketuksen välttämiseksi, ja rochinia käytetään pääasiassa ylöspäin suunnatuissa pistämisliikkeissä haavoittuviin kohtiin kylkiluiden alla, kainalossa ja kurkussa. Matayoshi Kobudo säilyttää vastaavan katan: Timbei no Kata, käyttäen kilpeä seiryuton (macheetti-terä) kanssa keihään sijaan.
