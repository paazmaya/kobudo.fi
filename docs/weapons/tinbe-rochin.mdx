# Tinbē-Rochin (ティンベー・ロチン)

**Tinbē-Rochin** (ティンベー・ロチン) on pari-ase yhdistelmä: **tinbē** on pieni pyöreä kilpi perinteisesti tehtävä risuista, nahasta tai **kilpikonnan kuoresta**, kun taas **rochin** on lyhyt keihäs tai terä. Yhdistelmä on yksi visuaalisesti erottuneista Ryukyu kobudossa ja ainoa ase-pari, joka yhdistää puolustus-esine ja hyökkäys-aseen yksikönä.

JRKF "Mitä on Ryukyu Kobudo" -sivun mukaan **tinbē** (kilpi) ja **rōchin** (lyhyt keihäs) muodostavat pari-ase joukon. Kilpet tehtiin perinteisesti **risusta, nahasta tai kilpikonnan kuoresta**, kun taas rōchin voitaisiin olla lyhyt keihäs tai **machete-kaltainen terä (seiryuto / 青龍刀)**, ja molempia voitaisiin käyttää huijauksiin, sokaisemiseen, leikkaukseen ja työntöön. Nykyaikainen tinbē voidaan tehdä **kevyistä seoksista tai puusta**, mutta taktiikka ajatuksia jäävät: **käytä kilpeä suojaukseen, näkemisen häiriintöihin ja reunaisku iskuihin, kun taas rochin pistää ja leikkaa**, toistaa eteläisen kiinalaisen kilpi-ja-keihäs-systeemin.

揆奮館 jäljittää tinbē-tekniikat takaisin **etelä Shaolin (南派小林拳の流れをくむ)** ja väittää, että ne olivat todellisessa käytössä **Three Kingdoms (三山) jaksolla**, tekee tinbē yhdeksi **vanhimmista kerroksista** Ryukyu-aseen harjoittelusta.

## Fyysiset ominaisuudet

| Komponentti     | Ominaisuus             | Yksityiskohta                                              |
| --------------- | ---------------------- | ---------------------------------------------------------- |
| Tinbē (kilpi)   | Koko                   | ~45 cm pitkä × 38 cm leveä                                 |
|                 | Perinteinen materiaali | Merikilpikonnan kuori tai kudottu rottinki/köynnös         |
|                 | Moderni korvike        | Kovetettu nahka tai puu                                    |
| Rochin (keihäs) | Pituus                 | Vastaava kuin kyynärvarren pituus                          |
|                 | Muoto                  | Lyhyt keihäs, lyhyt miekka tai macheetti (seiryuto) -muoto |
|                 | Materiaali             | Metalli, luu tai kovakoinen puu                            |

## Taktinen logiikka

Tämä yhdistelmä on epätavallinen kansainvälisillä mittapuilla, sillä useimmat asejärjestelmät eivät parittele omistettua puolustusvälinettä hyökkäysaseen kanssa. Tinbē mahdollistaa taistelun lähietäisyydellä, jossa pitkä ase olisi kömpelö: kilpi torjuu, rochin työntää tai leikkaa samalla liikkeellä. Liike on tyypillisesti matala ja väistävä, käyttäen kilpeä kulmien luomiseen rochinille aukkojen hyödyntämiseksi.

## Kata

Tairan opetussuunnitelma sisältää yhden ensisijaisen tinbē-rochin-katan:

- **Hamahiga no Tinbē** (浜比尌のティンベー): Peruskata, joka kattaa jalkatyön, kilven kulmat ja työntöyhdistelmät. Liike on tyypillisesti ympyrämäistä liiallisen kilpikosketuksen välttämiseksi, ja rochinia käytetään pääasiassa ylöspäin suunnatuissa pistämisliikkeissä haavoittuviin kohtiin kylkiluiden alla, kainalossa ja kurkussa. Matayoshi Kobudo säilyttää vastaavan katan: Timbei no Kata, käyttäen kilpeä seiryuton (macheetti-terä) kanssa keihään sijaan.
