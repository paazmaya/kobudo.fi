# Styles & Lineages

| Lineage | Main Characteristics |
| :--- | :--- |
| **Taira Line** | Preservation focused, 8 core weapons. |
| **Matayoshi** | Chinese-influenced (Kingai-ryu), complex movements. |
| **Yamane-ryu** | Fluid, long-range staff (Bojutsu). |

![Lineage Chart](https://placehold.co/800x400/333333/white?text=Kobudo+Lineage+Chart)

Key styles include the Taira Line (Hozon Shinkokai), Matayoshi Kobudo, and Yamane-ryū. Each has unique technical approaches to the staff (Bō).
