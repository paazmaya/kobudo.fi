# Image Generation Prompts — kobudo.fi

Prompts are written for the **Illustrious XL** model (Danbooru tag syntax, comma-separated, lowercase).  
All images share a consistent look: **traditional illustration / woodblock print style** with a **dark crimson** background palette matching the site's `#4a0000` colour.

## Shared Settings

**Negative prompt (apply to all):**
```
monochrome, greyscale, multiple views, text, watermark, signature, translation request, comic, 4koma, 2koma, modern clothing, photography, 3d render, blurry, low quality
```

**Generation settings (recommended):**
- Sampler: DPM++ 2M Karras
- Steps: 30–40
- CFG: 7–8
- Resolution: match original placeholder dimensions (see each section)
