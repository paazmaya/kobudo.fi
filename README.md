# kobudo.fi

> Telling about Ryukyu martial arts with weapons

This website is built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

Use this Docusaurus installation as a starting point for:
Create a prominently dark red static web site, using Docusaurus to build it, tailwind CSS and markdown to specify page contents. 
The other colors should be monochrome, few shades of grey, accessibility in mind to get WCAG 2.2 AAA passing.
I will add plenty of images based on the content later, for now use placeholders, preferably with picture element to provide responsive and optimized experience.
The site should support english and finnish, reflected by the base url /en/ or /fi/. Accessing front page at kobudo.fi/ would use the browsers language preference list, but would default to finnish, as the domain is in finland.
The site tells about ryukyu martial arts that use weapons, that are described in the attached docs. Use that information to structure the site in sections of history, styles, weapons.
There should be possibility to extend and add further sub sections and more details to each topic later. About page should also be there. Start creating everything with the english version first, as the data provided is also in english. Use big hit areas, not only for mobile but always and dont make many differences with mobile and desktop, just the layout.
Ask first to clarify anything is unclear
