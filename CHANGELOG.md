# Changelog of kobudo.fi

All notable changes to this project will be documented in this file.

## [v0.3.0] - 2026-04-01

- Playwright end-to-end testing for search, 404 pages, and internal linking
- Script to detect unused CSS definitions
- Custom 404 page with dedicated banner image
- HTTP security headers for improved web performance
- Social media preview images specific to each page
- Redirect handling for broken external links
- Switched from Prettier to [Oxfmt](https://oxc.rs/docs/guide/usage/formatter.html) for faster formatting
- Moved oxfmt to run against MDX files
- Optimized image loading and added preconnect to Microsoft Clarity
- Consistent banner styles across documentation pages
- Accessibility improvements targeting AAA compliance
- Navigation styles refined for better usability
- Added workflow permissions to CI configuration

## [v0.2.0] - 2026-03-15

- Research content on Taira Shinken and his students
- Microsoft Clarity integration for usage analytics
- Build date and technical details on About page
- CSS sizing units switched from pixels to rem for better accessibility
- Prettier configured and applied to codebase
- Search and menu color improvements
- Simplified language throughout documentation for non-native English speakers
- Enhanced internal linking for better discoverability
- Added Yamane Ryu research notes
- Added kata lineage documentation
- Expanded Taira-related content with references

## [v0.1.0] - 2026-03-12

- Initial Docusaurus site setup
- Bilingual support (English and Finnish) with localized URLs
- Image generation prompts for AI-generated illustrations
- 32-color PNG image optimization for all site graphics
- Progressive Web App (PWA) configuration
- Research documentation with references on each page
- Documentation covering:
  - Kobudo history and kata transmission
  - Weapon documentation (bo, sai, tonfa, etc.)
  - Matayoshi Kobudo style information
  - Research notes and bibliography
